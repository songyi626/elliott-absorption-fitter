# 吸收光譜擬合工具 — Elliott Formula (激子吸收 + 連續態吸收)

以 Python + PyQt5 撰寫的桌面 GUI 程式，用來擬合半導體 / 鈣鈦礦材料吸收光譜，
模型採用附加 sech 展寬的 Elliott formula：

```
α(E) = α0 [ Σ_{n=1}^∞ (4E0)/(n-1/2)^3 · sech((E-Eg+Eb^n)/Γex)   ← 激子吸收 α_ext
            + ∫_{Eg}^∞ sech((E-x)/Γc) · F(E) · 1/(1-b(x-Eg)) dx ] ← 連續態吸收 α_cont

Eb^n = E0 / (n-1/2)^2   (激子束縛能)
F(E) = 2 / (1 + exp(-2π√(E0/(E-Eg))))   (Sommerfeld enhancement factor)
```

參考文獻: S. Neutzner *et al.*, *Phys. Rev. Mater.* **2**, 064605 (2018)。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `elliott_model.py` | Elliott formula 的物理模型 (激子項、連續態項、總合)，已向量化以加速運算 |

## 安裝

建議使用 Python 3.9 以上版本。

```bash
pip install -r requirements.txt
```

若在 Linux 上遇到 Qt 平台外掛（xcb）相關錯誤，通常安裝系統套件
`libxcb-cursor0` 或設定環境變數 `QT_QPA_PLATFORM=xcb` 即可解決。

## 執行

```bash
python3 main_app.py
```

資料夾裡附上了 `launch_app.bat` 與 `launch_app.vbs` 兩個檔案，設定一次之後，
以後只要雙擊桌面捷徑就能直接開啟程式，不用再打開 Anaconda Prompt、`conda activate`、`cd`。

### 步驟 1：找出你 conda 環境的 Python 路徑

1. 開啟 Anaconda Prompt
2. 輸入：`conda activate absfit` (換成你自己的環境名稱)
3. 輸入：`where pythonw`
4. 會印出一行路徑，例如：
   ```
   C:\Users\你的帳號\anaconda3\envs\absfit\pythonw.exe
   ```
   把這一整行複製起來。

### 步驟 2：修改 `launch_app.bat`

用記事本打開 `launch_app.bat`，找到這一行：

```bat
set ENV_PYTHON=C:\Users\%USERNAME%\anaconda3\envs\absfit\pythonw.exe
```

把等號後面的路徑換成你步驟 1 複製的路徑，存檔。

> 如果你的 Anaconda 是裝在 `C:\ProgramData\Anaconda3` 或環境名稱不是 `absfit`，
> 用步驟 1 查到的真實路徑取代即可，不用自己猜。

### 步驟 3：建立桌面捷徑

在 `launch_app.vbs` 上按右鍵 → **傳送到 → 桌面 (建立捷徑)**。
之後**雙擊桌面上這個捷徑**，就會直接開啟程式，完全不會跳出黑色的命令視窗。

> 想換一個好看的圖示？在桌面捷徑上按右鍵 → 內容 → 變更圖示，
> 選一個喜歡的 `.ico` 檔即可（跟程式本身的執行無關，純粹好看）。

### 疑難排解

- **雙擊捷徑沒反應**：先直接雙擊 `launch_app.bat`（不是 vbs）看看有沒有跳出錯誤訊息，
  通常是 `ENV_PYTHON` 路徑打錯或環境名稱不對。
- **想確認路徑對不對**：在 Anaconda Prompt 裡直接貼上該路徑執行，
  例如 `"C:\Users\你的帳號\anaconda3\envs\absfit\pythonw.exe" --version`，
  能正常印出版本號就代表路徑沒問題。

## 2D / 3D 模型切換

目前程式支援兩種材料維度的 Elliott formula：

| 維度 | 適用材料 | 激子項係數 | 基態(n=1)束縛能 | 連續態 JDOS |
|---|---|---|---|---|
| **2D / Quasi-2D** | 二維或準二維材料 (例如層狀鈣鈦礦) | `4E0/(n-1/2)^3` | `Eb(n=1) = 4×E0` | 常數 (2D JDOS) |
| **3D Bulk** | 三維塊材半導體 | `2E0/n^3` | `Eb(n=1) = E0` | ∝ √(E-Eg) |

在左側「模型維度」下拉選單切換即可，「自動估算初始值」與擬合結果摘要
（`Eb(n=1)`、`Eex(n=1)` 的換算）都會依所選維度自動調整公式。

> **切換維度後記得重新按一次「自動估算初始值」**，因為 Eg 的估算公式
> (`Eg = E_peak + Eb(n=1)`) 在兩種維度下的 `Eb(n=1)` 定義不同，
> 沿用另一維度算出的舊初始值可能會離真實值較遠。

## 使用流程

1. **匯入實驗數據**
   點選左側「匯入數據檔案」，選擇兩欄數值資料的檔案（能量 (eV)、吸收度），
   支援 `.txt` / `.csv` / `.dat`，逗號、Tab、空白分隔皆可自動辨識，
   文字表頭（非數字行）會自動略過。

2. **選擇擬合範圍**
   - 方法一：點擊「啟動『拖曳選擇範圍』」，接著直接在右側圖上以滑鼠拖曳，
     選取要參與擬合的能量區間（例如把測量雜訊很大的邊緣段排除）。
   - 方法二：直接在 `Emin` / `Emax` 輸入框輸入數值，按「套用範圍」。
   - 「重設為全部數據範圍」可還原成完整資料範圍。

3. **設定擬合參數**

   **最簡單的方式：先按「自動估算初始值」**
   程式會依你目前選擇的擬合範圍內的資料，自動抓出激子吸收峰的位置與寬度
   （用 `scipy.signal.find_peaks` 偵測峰值），並回填 `α0`、`Eg`、`E0`、
   `Γex`、`Γc`、`b` 六個初始值，同時順便設定合理的上下限。
   按下後可以直接接著做「4. 執行擬合」。

   如果你想手動調整，以下是各參數的意義與該怎麼填：

   | 參數 | 意義 | 怎麼抓初始值 |
   |---|---|---|
   | `Eg` | 能隙 | **最重要**。看資料吸收邊「快速上升」的位置，通常在激子峰的右側（能量較高處）一點 |
   | `E0` | 激子雷德堡能量 (同時等於基態束縛能 Eb) | **次重要**。多數材料約在 10–50 meV (0.01–0.05 eV)，鈣鈦礦類常見 20–30 meV |
   | `α0` | 整體振幅 | 抓資料的最大值量級即可，不用很精確 |
   | `Γex` | 激子峰的展寬 | 看激子峰的半高寬 (FWHM)，數值上比 FWHM 小 (sech 函數 FWHM ≈ 2.6×Γex) |
   | `Γc` | 連續態吸收的展寬 | 通常比 `Γex` 略大，可先設成 `Γex` 的 1.5–2 倍 |
   | `b` | 能帶非拋物線修正 | **最不敏感**，多數情況設 0–0.3 之間都可以，也可以先取消勾選「擬合」把它固定住，讓其他參數先收斂 |

   左側表格每個參數皆可設定「初始值」「下限」「上限」，並用核取方塊決定
   該參數是否參與擬合（取消勾選即固定該參數不變）。
   下方另可設定 `n_max`（激子求和項數，預設 8）與 `x_upper`
   （連續態積分的能量上限，預設 10 eV），這兩個通常不需要更動。

   > **小技巧**：如果自動估算後擬合結果不理想（例如某參數卡在上下限邊界），
   > 可以試著：(1) 先取消勾選 `b` 和 `Γc` 讓它們固定，只讓 `Eg`、`E0`、
   > `Γex`、`α0` 先收斂，擬合成功後再勾選 `b`、`Γc` 繼續微調；
   > (2) 手動放寬對應參數的上下限範圍。

4. **執行擬合**
   選擇演算法（`leastsq` 最快；若不易收斂可嘗試 `least_squares` 或 `nelder`），
   按下「開始擬合 (Fit)」。

5. **檢視結果**
   - 左側「擬合結果」表格會列出每個參數的擬合值與標準誤差。
   - 下方文字框顯示 R²、reduced chi-square、殘差平方和，
     以及基態(n=1)激子束縛能 `Eb(n=1) = 4×E0`（注意：公式 `Eb^n = E0/(n-1/2)²`，
     n=1 時 `(n-1/2)²=0.25`，故 `Eb(n=1)=E0/0.25=4E0`，並非直接等於 E0），
     與對應的激子峰理論位置 `Eex(n=1) = Eg - Eb(n=1) = Eg - 4E0`。
   - 右側圖上會疊加畫出：
     - 黑色散點：實驗數據
     - 橘色虛線：激子吸收項 α_ext
     - 綠色點虛線：連續態吸收項 α_cont
     - 紅色實線：兩者相加的總合擬合曲線

6. **匯出結果（可直接匯入 Origin 作圖）**
   - 「匯出數據 + 擬合曲線」：輸出 tab 分隔（或 `.csv`）文字檔，
     欄位為 `Energy(eV)`、`Absorbance_exp`、`Fit_Total`、
     `Excitonic_absorption`、`Continuum_absorption`，
     所有 Y 欄共用同一個 X 欄 (能量)。
     在 Origin 中用 **File > Import > Single ASCII** 開啟此檔即可，
     第一欄設為 X，其餘四欄設為 Y，分別畫成散點/實線/虛線並指定不同顏色。
   - 「匯出擬合參數摘要」：輸出純文字檔，記錄所有擬合參數、誤差、
     擬合範圍與統計量，方便寫報告或論文時引用。

## 物理模型的實務近似說明

- **連續態的 Sommerfeld/JDOS 增強因子計算方式（重要）**：
  這個版本把增強因子改成用**積分變數 x**（連續態內部的真實躍遷能量）來計算，
  而不是用外層的**光子能量 E**。也就是：先算出「裸連續態吸收譜」
  （JDOS × Sommerfeld enhancement，是 x 的函數），再用 `sech((E-x)/Γc)`
  對它做展寬摺積，得到量測到的吸收度 α(E)。
  這比「直接在積分外用 E 計算增強因子」更符合物理上「展寬是量測解析度造成的
  摺積效應」這個圖像，但**這與最原始截圖公式字面上的寫法不同**
  （截圖裡增強因子用的是 `E-Eg`）。如果你需要跟論文或其他人核對公式，
  記得說明你用的是這個「以 x 計算增強因子」的版本。

- 連續態積分公式中 `x-Eg` 在 x=Eg（積分下限）時會使 `√(E0/(x-Eg))` 分母為 0。
  本程式加上極小值下限 (`EPS`) 讓函數在能隙處平滑過渡，這是文獻擬合程式
  常見的工程近似。

- `1-b(x-Eg)` 分母若趨近 0 會發散，程式同樣加上安全下限避免數值爆掉。
- 連續態積分改以**固定格點的向量化梯形積分**取代逐點自適應積分，
  在保有足夠精度（`x_upper` 可調整積分範圍、程式內部格點數為 400 點）
  的前提下大幅提升擬合速度。

## 常見問題

**Q: 擬合跑不動 / 卡住？**
A: 連續態積分在極端參數（例如 `Gamma_c` 或 `Gamma_ex` 逼近下限 0.0001）時
可能導致函數變化劇烈，建議適度限制參數上下限，或先固定 `b`、`Gamma_c`
等較不敏感的參數，讓 `Eg`、`E0` 先收斂，再逐步放開其他參數精修。
程式內建有 `max_nfev`（最大函式評估次數）安全上限，即使參數設定不理想、
優化器陷入難以收斂的區域，也會在有限時間內停止並回報「無法收斂」，
不會無限期卡住；如果跳出這個訊息，代表要重新檢查初始值或邊界設定，
而不是程式當機。

**Q: 切換 2D/3D 或按「自動估算初始值」後，Eg 的上下限跳到很誇張的範圍（例如 0.1~8 eV）？**
A: 這是已修正的問題。`Eg` 是絕對能量值，程式現在會以「估計值 ± 目前選擇範圍的一半
（至少 ±0.3 eV）」設定上下限，而不是用「估計值 × 倍數」，避免優化器
在不合理的能量範圍內遊走導致擬合極度緩慢。

**Q: 擬合結果 R² 很高，但參數看起來不合理（例如 b 跑到邊界值）？**
A: 這通常代表參數之間存在簡併（多組參數組合可給出幾乎相同的曲線）。
請善用「固定擬合」核取方塊，先固定較不確定的參數（如 `b`），
或改用更貼近文獻/合理物理範圍的初始值與上下限。

**Q: 想匯出更多取樣點的平滑曲線（不受限於實驗數據點的疏密）？**
A: 目前匯出的曲線是在「實驗數據點所在的能量位置」上計算模型值，
方便與原始數據在 Origin 中對齊。如需更細緻的平滑曲線，
可在 `main_app.py` 的 `on_export_curves` 中，將 `E_used`
換成 `np.linspace(E_used.min(), E_used.max(), 1000)` 這類更密集的陣列
再重新計算 `get_component_curves`。
